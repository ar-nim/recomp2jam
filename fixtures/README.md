# Fixtures

Only **synthetic, MIT-licensed** test files live here — generated by our own
code or hand-crafted hex. They exist so `cargo test` never needs the
original game data.

Rules:

- Never add files extracted from the original client or installer
  (`.ojm`, `.ojn`, `.ojt`, `.exe`, artwork, music).
- Name fixtures by purpose: `ojm-minimal-<case>.bin`,
  `ojn-minimal-<case>.bin`.
- Document the generator (unit test or script) that produced each fixture.

Currently fixtures are generated in-memory by unit tests; this directory
tracks the convention for when we add golden files.
